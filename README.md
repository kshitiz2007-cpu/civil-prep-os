# Civil Prep OS

A personal civil-services preparation operating system focused on learning, retention, practice, knowledge organization, adaptive planning, and measurable competence.

## Stack
- React + TypeScript
- Vite
- Local browser persistence for the first milestone

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Status
The first foundation milestone is underway: workspace shell and Command Center dashboard.
